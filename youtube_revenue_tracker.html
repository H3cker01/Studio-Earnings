Step-by-Step Google Cloud Setup:

  1. Go to Google Cloud Console and create a project.
  2. In APIs & Services > Library, enable YouTube Analytics API.
  3. In OAuth consent screen, select External, set scope: yt-analytics-monetary.readonly, and add your channel email under Test Users.
  4. In Credentials, click Create Credentials > OAuth client ID:
    • Application Type: Web Application
    • Authorized JavaScript Origins: https://yourusername.github.io
  5. Copy the Client ID and paste it in the box above!
